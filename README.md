# 整備格納庫見学サイト（試作）

## 概要

整備格納庫見学の内容を写真で紹介し、注意事項の確認から申込フォームの完了画面までを試せる静的サイトです。これはユーザーテスト用の試作で、予約は成立せず、氏名や連絡先は送信・保存されません。

## Usage

GitHub Pagesで公開する配信ファイルです。ローカルで確認する場合は、このディレクトリで `python3 -m http.server 8080` を実行し、`http://localhost:8080/` を開いてください。

写真はスクロールに合わせて中央へズームします。続く2枚の写真は同じ表示サイズで、縦スクロールに合わせて横へ切り替わります。動きを減らす設定では静止表示になります。

## なぜこの技術を選んだか

要件でReactを指定しており、注意事項の確認や申込フォームの状態を画面内で管理できます。サーバーへの送信が不要なので、Reactを同梱した静的なHTML・CSS・JavaScriptにしました。GitHub Pagesなら配信に常時起動するローカルサーバーが不要です。スクロール演出は追加ライブラリを使わず、CSSと `requestAnimationFrame` で実装しています。
